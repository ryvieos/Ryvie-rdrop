# Ryvie-rdrop

**English** · [Français](README.fr.md)

> Part of the [Ryvie](https://github.com/ryvieos/Ryvie) ecosystem, the self-hosted personal cloud OS. Learn more at [ryvie.fr](https://ryvie.fr).

Ryvie-rdrop is local file sharing that runs right in your browser. Send photos, documents and any file between devices on the same network in an AirDrop style, with nothing to install. It is the self-hosted file sharing app of the Ryvie personal cloud, so your files never leave your network and no account is ever required.

Ryvie-rdrop is a self-hosted fork of [Snapdrop](https://github.com/RobinLinus/snapdrop).

## Features

- Local, browser-based file sharing between devices on the same network
- AirDrop-style experience that works across phones, tablets and computers
- No account and no sign-up needed
- Files stay on your network and never leave your devices
- Comes with a companion mobile app for an even smoother experience
- Self-hosted and part of the Ryvie personal cloud

## Structure

The repository ships two components:

- `rDrop-main` — the web application. This is the browser-based file sharing app, a fork of Snapdrop, that lets devices on the same network discover each other and exchange files.
- `ryvie-mobile-app` — the companion mobile client. It brings the same local file sharing experience to a native mobile app.
