# Ryvie-rdrop

[English](README.md) · **Français**

> Fait partie de l'écosystème [Ryvie](https://github.com/ryvieos/Ryvie), l'OS de cloud personnel auto-hébergé. Plus d'infos sur [ryvie.fr](https://ryvie.fr).

Ryvie-rdrop est un partage de fichiers local qui fonctionne directement dans votre navigateur. Envoyez photos, documents et n'importe quel fichier entre les appareils du même réseau, à la manière d'AirDrop, sans rien installer. C'est l'application de partage de fichiers auto-hébergée du cloud personnel Ryvie, donc vos fichiers ne quittent jamais votre réseau et aucun compte n'est requis.

Ryvie-rdrop est un fork auto-hébergé de [Snapdrop](https://github.com/RobinLinus/snapdrop).

## Fonctionnalités

- Partage de fichiers local, dans le navigateur, entre les appareils du même réseau
- Expérience façon AirDrop qui fonctionne entre téléphones, tablettes et ordinateurs
- Aucun compte et aucune inscription nécessaires
- Les fichiers restent sur votre réseau et ne quittent jamais vos appareils
- Livré avec une application mobile compagnon pour une expérience encore plus fluide
- Auto-hébergé et intégré au cloud personnel Ryvie

## Structure

Le dépôt contient deux composants :

- `rDrop-main` — l'application web. C'est l'application de partage de fichiers dans le navigateur, un fork de Snapdrop, qui permet aux appareils du même réseau de se découvrir et d'échanger des fichiers.
- `ryvie-mobile-app` — le client mobile compagnon. Il apporte la même expérience de partage de fichiers local dans une application mobile native.
